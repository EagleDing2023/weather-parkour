# 04: Treasure and the Rickroll link

Status: ready-for-agent
Blocked by: 02, 03

## What to build

The Treasure chest at the end of the Course. Opening it stops the timer and opens the Rickroll link in a new tab. A results screen shows the time with options to play a new Course or return to the menu.

## Acceptance criteria

- [ ] The Treasure is placed at the Course end from the generator.
- [ ] The player opens it with a key press or click while touching it.
- [ ] Opening it stops the timer and opens the link in a new tab, triggered directly from the key press or click so the browser's pop-up blocker allows it.
- [ ] The game stays on the finished Course, and shows the time, plus "new Course" (fresh seed) and "menu".

## Notes

The exact URL is not decided. Ask the user for it before building; do not guess one.
